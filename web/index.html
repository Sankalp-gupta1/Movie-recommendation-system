Content-based recommendation

Pick one movie. Find the next five.

The original repository was empty. This hosted version now includes a real content-based recommender that compares genre and theme tags using cosine-style overlap scoring.

How it works: each movie is represented by genre/theme tokens. The app weights exact tag overlap, genre overlap and release-era proximity, then ranks every other title. It is deterministic and runs entirely in the browser—no API key or database.
